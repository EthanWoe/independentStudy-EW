# Power Platform Fundamentals (PL-900) Notes

## Big Picture
- Power Platform is a collection of tools used to build solutions with data
- Focus on low-code and no-code development
- Main purpose: help users create apps, automate processes, analyze data, and build chatbots

---

## Exam Topics
- Power Platform components
- Power Apps
- Power Automate
- Power BI
- Power Virtual Agents
- Dataverse
- Connectors
- AI Builder

---

## Terminology Changes

| Old | New |
|-----|-----|
| Common Data Service | Dataverse |
| Entity | Table |
| Field | Column |
| Record | Row |

---

## Power Apps
Used to create applications

### Types of Apps
- Canvas Apps
  - UI designed manually
  - Drag-and-drop interface
  - Can connect to multiple data sources
  - Layout: phone or tablet

- Model-driven Apps
  - Built on Dataverse
  - UI generated automatically
  - Focus on data structure
  - Less UI control

- Power Pages (Portals)
  - External-facing websites
  - Accessible by users outside the organization

---

## Power Automate
Used to automate workflows

### Types of Flows
- Automated Flow
  - Triggered by an event

- Instant Flow
  - Triggered manually

- Scheduled Flow
  - Runs at set times

- Desktop Flow (RPA)
  - Records and automates user actions

- Business Process Flow
  - Guides users through a process

---

## Power BI
Used for data analysis and visualization

- Creates reports and dashboards
- Connects to multiple data sources
- Used for business insights

---

## Power Virtual Agents
Used to create chatbots

### Components
- Topics
  - Define conversation paths

- Entities
  - Understand user input

- Actions
  - Perform operations (often through Power Automate)

---

## Dataverse
Central data storage system

- Stores data in tables
- Tables contain:
  - Columns
  - Rows
- Supports:
  - Relationships between tables
  - Security roles
  - Business rules

---

## Connectors
Used to connect to external services and data sources

- Enable communication between Power Platform and other systems
- Types:
  - Standard connectors
  - Premium connectors

Examples:
- SharePoint
- Outlook
- SQL Server
- Azure services

---

## AI Builder
Adds AI capabilities

Examples:
- Form processing
- Object detection
- Text recognition
- Sentiment analysis
- Predictions

---

## How Components Work Together
- Power Apps: interface
- Power Automate: automation
- Power BI: reporting
- Power Virtual Agents: chatbot interface
- Dataverse: data storage
- Connectors: integration layer

---

## Key Relationships
- Apps can trigger flows
- Flows can update data in Dataverse
- Power BI can use data from Dataverse
- Virtual Agents can trigger flows
- All components can use connectors

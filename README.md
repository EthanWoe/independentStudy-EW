### Certification Path: Azure Fundamentals, Azure Admin Associate, Power Apps Fundamentals

* **Azure Fundamentals**
    * The initial objective was to pass the Azure Fundamentals exam. Preparation focused primarily on memorizing terminology and core concepts. Despite scheduling challenges, the exam was successfully completed and I received the [certification](https://github.com/EthanWoe/independentStudy-EW/blob/main/Work/azure/azureFundamentals/AzureCert.jpg).
* **Azure Admin Associate**
  * Was extremely course-intensive, and after doing research, I learned that even people who used Azure on a day-to-day basis found it was an extremely hard exam. When I learned this about halfway through, I decided that due to time, and my lack of experience on Azure programs i would put a hold on this for now and continue later in my career.
 * **Power App Fundamentals**
    * Started Power Apps and simply did not like it, so after discussing, we decided to move the independent study in a different direction

* **Hands-On Azure**
    * The switch to Hands on was decided to be best as I got a job as a junior sys admin position, so familiarizing myself with Azure would help my start go smoother and faster. This was also something that was mentioned earlier, but was pursued after talking about Azure admin exam and my dislike of Power Apps.

* **What it gave**
  * Valuable experience creating A test environment  with multiple users and groups configured via CSV import. Role-based access control (RBAC) was tested by assigning varying permission levels and validating access through user logins. This allowed me to use some of the things I learned about in my earlier studies, such as RBAC, Conditional Access, Tags, Groups, and permissions.

These terms will make you sound professional and will help employers, peers, and professors condifdence and respedct for when you are talking about something in this field. These would be good intro assignments for the start of the Sys Admin Class to assist them with their learning, allowing them to draw connections with what they are doing in AWS.
   
    * **Assignment One:** Core System Architecture
        * Goes over the basics of different service types such as on-prem, IAAS, PAAS, SAAS. This is fundamental knowledge that is needed. Asking questions about these during an interview or during the job will be very bad.
    *** Assignment Two:** Essential technical terminology
        * Similar to assignment one, just essential technical jargon that is needed to know when you are going to be interviewing or working as a sys admin
